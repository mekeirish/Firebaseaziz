1. الوصول إلى وحدة التحكم وتسجيل الدخول

  1. افتح المتصفح وانتقل إلى الرابط console.firebase.google.com.
  2. سجل الدخول باستخدام حساب Google / Gmail الخاص بك.
  3. بمجرد الانتقال إلى لوحة التحكم، انقر على الزر الكبير "إضافة مشروع" (Add project).
💡 نصيحة: استخدم حساب جوجل المرتبط بالحساب الذي تخطط من خلاله لإدارة تطبيقاتك.

2. تكوين المشروع

  1. اسم المشروع: اكتب اسم تطبيقك (مثال: MonAppTest) ووافق على الشروط والأحكام.
  2. Google Analytics (تحليلات جوجل): سيطلب منك Firebase تفعيل هذه الميزة.
    • بالنسبة لمشروع بسيط أو تجريبي، يمكنك تعطيل هذا الخيار.
    • انقر على "إنشاء المشروع" (Create project).
  3. انتظر بضع ثوانٍ بينما يقوم جوجل بإعداد البنية التحتية الخاصة بك، ثم انقر على "متابعة" بمجرد الانتهاء.

3. إضافة تطبيق ويب (Web App)

  1. في الصفحة الرئيسية لمشروعك الجديد، ستظهر لك عدة أيقونات (iOS و Android و Web و Unity).
  2. انقر على أيقونة الويب </>.
  3. اكتب اسمًا مستعارًا لتطبيقك (مثال: Web App 1).
  4. اترك خيار Firebase Hosting غير محدد في الوقت الحالي.
  5. انقر على "تسجيل التطبيق" (Register app).

4. استرداد رمز التهيئة (Configuration)

  1. سيعرض لك Firebase الآن كتلة كود JavaScript تحت عنوان "إضافة حزمة تطوير البرامج SDK لـ Firebase".
  2. حدد موقع الكتلة التي تشبه الشكل التالي: 
    const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "...firebaseapp.com",
  projectId: "...",
  // ...
};
  3. قم بانسخ هذا الكود بالكامل.
  4. يمكنك الآن لصقه في أداة Firebase Injector أو إعطائه للذكاء الاصطناعي لدمجه في مشروعك!
